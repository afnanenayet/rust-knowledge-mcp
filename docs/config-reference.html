rust-knowledge

Search documentation of the resolved Cargo dependency universe of a workspace

Options

ArgumentShortValueDefaultRequiredDescription
--manifest-pathPATHBUF (optional)unsetPath to a Cargo.toml manifest. Defaults to the current directory.
--index-dirPATHBUF (optional)unsetDirectory for the knowledge index. Defaults to <workspace>/.rust-knowledge or $RUST_KNOWLEDGE_INDEX_DIR.
--verbosevBOOLfalseVerbose logging.
--helphBOOLfalseShow help message and exit.
--versionVBOOLfalseShow version and exit.

rust-knowledge search

Search the knowledge index.

Usage: rust-knowledge search [OPTIONS] <QUERY>

ArgumentShortValueDefaultRequiredDescription
<QUERY>STRING—yesFree-form query: natural language or Rust identifiers.
--packageSTRING (repeatable)(empty list)Restrict to these packages (name or name@version). Repeatable.
--source-kindSTRING (repeatable)(empty list)Restrict to source kinds (rustdoc_item, rustdoc_module, crate_readme, markdown_document). Repeatable.
--item-kindSTRING (repeatable)(empty list)Restrict to item kinds (function, struct, trait, ...). Repeatable.
--limitUSIZE8Maximum number of results.
--jsonBOOLfalseEmit JSON (one hit per line).
