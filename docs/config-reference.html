rust-knowledge

Version 0.1.0

Usage

rust-knowledge [OPTIONS] <COMMAND>

Commands

packages List the packages in the resolved Cargo dependency universe.

Usage rust-knowledge packages [OPTIONS]

Options

NameDescription
--json

Emit JSON (one object per line).
dump-docs Build the normalized documentation corpus and print it (debug view).

Usage rust-knowledge dump-docs [OPTIONS]

Options

NameDescription
--package <STRING>Optional value

Only documents of this package (name or name@version).

--rustdoc-scope <STRING>Default workspace

Which packages get rustdoc JSON generated.

--prebuilt-rustdoc <PATHBUF>Optional value

Read prebuilt rustdoc JSON artifacts from this directory instead of invoking cargo.

--json

Emit one JSON document per line.
index Build the persistent knowledge index for the workspace.

Usage rust-knowledge index [OPTIONS]

Options

NameDescription
--rustdoc-scope <STRING>Default workspace

Which packages get rustdoc JSON generated.

--toolchain <STRING>Optional value

Toolchain used for rustdoc generation (default: nightly).

--prebuilt-rustdoc <PATHBUF>Optional value

Read prebuilt rustdoc JSON artifacts from this directory instead of invoking cargo.
search Search the knowledge index.

Usage rust-knowledge search [OPTIONS] <QUERY>

Arguments

NameDescription
<QUERY>Required

Free-form query: natural language or Rust identifiers.

Options

NameDescription
--package <STRING>Default list[0]

Restrict to these packages (name or name@version). Repeatable.

--source-kind <STRING>Default list[0]

Restrict to source kinds (rustdoc_item, rustdoc_module, crate_readme, markdown_document). Repeatable.

--item-kind <STRING>Default list[0]

Restrict to item kinds (function, struct, trait, ...). Repeatable.

--limit <USIZE>Default 8

Maximum number of results.

--json

Emit JSON (one hit per line).
get Retrieve one document by its stable id.

Usage rust-knowledge get [OPTIONS] <ID>

Arguments

NameDescription
<ID>Required

Document id (as printed by search).

Options

NameDescription
--json

Emit the full JSON document.
symbol Look up a symbol by (partial) path.

Usage rust-knowledge symbol [OPTIONS] <SYMBOL>

Arguments

NameDescription
<SYMBOL>Required

Symbol path or last segment, e.g. demo_core::writer::Writer::flush or spawn_blocking.

Options

NameDescription
--package <STRING>Default list[0]

Restrict to these packages (name or name@version). Repeatable.

--json

Emit JSON (one entry per line).
eval Run the retrieval evaluation set against the knowledge index.

Usage rust-knowledge eval <FILE>

Arguments

NameDescription
<FILE>Required

Path to the eval file (TOML, [[case]] entries).
config-docs Write the HTML configuration reference page.

Usage rust-knowledge config-docs [OPTIONS]

Options

NameDescription
--output <PATHBUF>Optional value

Output file path (defaults to docs/config-reference.html).

Configuration

When a field is set in more than one place, precedence is CLI > Environment > Config file > Defaults.

Supported file formats: .json.

Top-Level Options

NameDescription
--manifest-path <PATHBUF>Optional value

Path to a Cargo.toml manifest. Defaults to the current directory.

--index-dir <PATHBUF>Optional value

Directory for the knowledge index. Defaults to <workspace>/.rust-knowledge or $RUST_KNOWLEDGE_INDEX_DIR.

--cargo <PATHBUF>Optional value

Explicit cargo binary for metadata/rustdoc invocations. Defaults to cargo on $PATH, or $RUST_KNOWLEDGE_CARGO.

--log <STRING>Optional value

Tracing env-filter (e.g. "info", "demo_core=debug"). -v overrides it with "debug".

-v, --verbose

Verbose logging (forces the "debug" filter).

-h, --help

Show help message and exit.

--html-help

Open HTML help in the browser and exit.

-V, --version

Show version and exit.

--completionsOptional value

Generate shell completions.

Export JSON Schema files for all config roots.
